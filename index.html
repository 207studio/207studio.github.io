    01PairyCore SDK

    A Swift package that streams a Mac screen to an iPad and sends input back.

    For Swift developers building a Mac + iPad remote app.

    • ScreenCaptureKit capture, H.264 or HEVC at 60 or 120 fps in Full HD.
    • Pointer, keys, Apple Pencil and clipboard come back over TLS 1.2.
    • Full source and 550+ tests. $129, one-time.

    02PPTX Player SDK

    A client-side engine that renders .pptx decks to HTML and SVG.

    For web and app developers who need to show PowerPoint decks.

    • Entrance, exit and emphasis effects, morph transitions and media.
    • Runs offline in any modern browser or a WKWebView.
    • No server conversion, no Office install. From $14, one-time.
    See details ↗
  3. 03Developer kit Scan-to-Grade A scanner batch in, a finished Excel gradebook out. See details ↗

    03Scan-to-Grade

    A Python package that turns a scanned batch into an Excel gradebook.

    For teachers and developers grading paper tests.

    • Reads the QR on each page and pairs fronts with backs.
    • Pages in any order or rotation get sorted out.
    • Scores, item analysis and a re-check list. Offline. From $79.
    See details ↗
  4. 04Developer kit OMR Auto-Grader Reads bubbles, O/X, circled words and ordering marks. See details ↗

    04OMR Auto-Grader

    A Python OMR engine for scanned answer sheets.

    For anyone grading scanned sheets with more than A to E bubbles.

    • Reads multi-answer marks, circled words, O/X boxes and ordering bubbles.
    • Fills in only the grades it is sure of.
    • Never overwrites a teacher's mark. The rest go to a re-check list.
    See details ↗

    • Exam paper, OMR sheet, answer key, explanations and a cover page.
    • One offline HTML file with live preview and autosave.
    • An MCP server lets an AI assistant draft exams. From $12.
