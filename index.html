Ttoryeot for Mac and Windows

Open 한글 files without 한글.

Free. HWP and HWPX files open as tabs, and short text in an HWPX file can be changed right on the page.

  • Open several HWP and HWPX files side by side as tabs.
  • Annotation mode (⌘⇧A) names each element as you hover, shows its path such as 표 > 2행 3열 > 문단 when you click, and lists every element inside an area you drag.
  • Double-click a paragraph in an HWPX file to change its text right on the page, then save it as HWPX with the formatting kept.

How these were made

Each pair comes from one HWPX file. The school notice was saved and exported to PDF in Hancom Office HWP for Mac 12.30.0 on 2026-11-03; the two short test pages were exported by Hancom on 2026-11-01. 또렷 0.1.0 (commit c534f93) rendered all three from those same saved files on 2026-11-04, using the same Hancom fonts. All PDFs were turned into 1240×1754 PNGs (150 dpi) with the same tool; nothing is cropped or retouched. The Hancom images come from Hancom's PDF export, not screenshots of the Hancom window. All documents are fictional and written by the 또렷 project.
