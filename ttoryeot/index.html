Engine

Ttoryeot (또렷) is our HWP/HWPX document engine, written in Rust. It opens 한글 documents fast and renders them faithfully to PDF or images. In HWPX files it can also change short text and keep the formatting.

For: anyone who needs to read or fix 한글 (HWP) files without 한글 installed.

  • Layout checked page by page against 한글 12.30 on real documents
  • Fast and light. Images in an 80-image file take 7 ms, down from 196 ms. Opening the same large document 20 times in a row in one program now peaks at about 125 MB, down from about 1 GB (one open: 165 MB → 118 MB)
  • One engine for Mac, iOS, Windows and the web (WASM)

Ttoryeot for Mac and Windows

Open 한글 files without 한글.

Free. Opens HWP and HWPX files, and edits HWPX text right on the page, as you see it, the way 한글 does.

  • Open HWP and HWPX files as tabs. Pages aim to look the way they do in 한글 12.30 for Mac.
  • A photo-only HWPX with several tall pictures in one paragraph now gives each picture its own page, so the second page no longer looks missing.
  • In an HWPX file, click any text and the cursor lands there. What you type is redrawn with the real fonts, spacing and line breaks, and character and paragraph formatting stay as they are.
  • Hold Ctrl on Windows or Cmd (⌘) on macOS and turn the mouse wheel to zoom the document from 25% to 400%.
  • ⌘S or Ctrl+S saves under a new name, never over the original file.
  • File > Print (⌘P on Mac, Ctrl+P on Windows) opens the system print dialog. It prints the current document body, including unsaved edits, without comments.
  • Pick a paragraph, table, picture or area and leave a comment; numbered pins on the page open it again. The document file is not changed.
  • With the MCP server (v0.3.2), an AI agent such as Claude Code or Codex can open a document in the app, read the comments you leave there, edit the HWPX in place and mark each comment resolved.

How these were made

Each pair comes from one HWPX file. The school notice was saved and exported to PDF in Hancom Office HWP for Mac 12.30.0 on 2026-11-03; the two short test pages were exported by Hancom on 2026-11-01. 또렷 0.1.0 (commit c534f93) rendered all three from those same saved files on 2026-11-04, using the same Hancom fonts. All PDFs were turned into 1240×1754 PNGs (150 dpi) with the same tool; nothing is cropped or retouched. The Hancom images come from Hancom's PDF export, not screenshots of the Hancom window. All documents are fictional and written by the 또렷 project.
