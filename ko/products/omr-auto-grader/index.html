무엇인가요

OMR Auto-Grader는 스캔한 답안지를 위한 Python OMR 엔진이에요. A부터 E까지의 버블을 넘어 복수 답안 표시, 동그라미 친 단어, O/X 상자, 순서 버블도 읽어요. 확실하게 읽힌 답만 성적에 채우고, 선생님이 이미 표시한 답은 덮어쓰지 않아요. 나머지는 다시 확인할 목록으로 보내요. 데모를 실행하면 Excel로 내보내요.

빠르게 시작하기

pip install -r requirements.txt
python demo.py
open out/

자주 묻는 질문

어떤 표시를 읽나요?

단일·복수 답안 버블, 동그라미 친 단어, O/X 상자, 순서 버블을 읽어요.

선생님이 이미 넣은 성적을 덮어쓰나요?

아니요. 확실하게 읽힌 답만 성적에 채우고, 선생님이 넣은 표시는 그대로 둬요. 선생님 표시와 다른 항목은 다시 확인할 목록에 올려요.

오픈 소스 대안도 있나요?

네. 예를 들어 버블 답안지용 OMRChecker(MIT)가 있어요. 이 엔진은 O/X, 동그라미 단어, 순서 문항과 확실하게 읽힌 답만 채우는 규칙을 더해요.

제 스캐너에서도 되나요?

스캐너 종류와 상관없이 스캔한 이미지에서 동작해요. QR Cropper와 함께 쓰거나, 둘 다 Scan-to-Grade Bundle로 받을 수 있어요.

구독인가요?

아니요. 1회 구매이고 전체 소스가 포함돼요.

AGPL 조건이 없는 상용 OMR 라이브러리가 있나요?

네. 이 엔진은 207studio 라이선스로 전체 소스와 함께 나와요. MarkShark는 AGPL이고 OpenMCR은 GPL-3예요.
