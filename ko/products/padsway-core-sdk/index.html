PadswayCore SDK: Mac 화면을 iPad로 스트리밍 (Swift)

무엇인가요

PadswayCore SDK는 macOS 13+와 iPadOS 17+에서 Mac 화면을 iPad로 보내는 순수 Swift 패키지예요. ScreenCaptureKit으로 화면을 잡고, VideoToolbox H.264/HEVC로 60 또는 120 fps(Full HD)로 인코딩·디코딩해요. iPad가 보내는 확인 응답에 맞춰 프레임을 조절해 지연을 낮게 유지하고, 포인터·키·텍스트·Apple Pencil·클립보드를 TLS 1.2와 페어링별 키로 되돌려 보내요. 전체 소스와 550개 이상의 테스트가 포함돼요.

빠르게 시작하기

swift build
swift run padsway self-test

자주 묻는 질문

Swift로 Mac 화면을 iPad에 스트리밍하려면 어떻게 하나요?

두 앱 모두에 PadswayCore를 넣어요. Mac에서는 Pairing을 만들고 HostSession을 시작해요. iPad에서는 페어링 정보를 불러와 ClientSession을 연결한 뒤, 넘겨주는 CVPixelBuffer를 그리면 돼요. 연결 방법은 INTEGRATION.md에 있고, 그 코드는 테스트에서 컴파일 검증을 거쳐요.

Mac이나 네트워크, 권한 없이도 시험해 볼 수 있나요?

네. `swift run padsway self-test`가 120개 프레임을 인코딩해서 루프백 TLS로 보내고 약 2초 안에 디코딩해요. ClientSession.demo()는 시뮬레이션한 Mac을 프로세스 안에서 스트리밍해서 온보딩과 App Review에 쓸 수 있어요.

Mac 쪽을 Mac App Store에 올릴 수 있나요?

아니요. 호스트가 손쉬운 사용(Accessibility) API로 입력을 주입하기 때문에 샌드박스에서 돌 수 없어요. 서명하고 공증한 앱으로 배포해야 해요. iPad 쪽은 이런 제한이 없어요.

다른 네트워크에서도 되나요?

기본으로는 같은 로컬 네트워크에서 동작해요. 포트 포워딩 없이 쓰고 싶을 때를 위해 오픈 소스 tsnet 라이브러리로 만든 선택형 브리지가 소스로 들어 있어요.

프레임 레이트와 해상도는 어떻게 되나요?

Full HD(1920×1080)예요. ProMotion iPad에서는 120 fps를 요청하고 다른 기기에서는 60 fps를 요청해요. 처리량을 보장하는 숫자는 아니에요. 네트워크 지연이 갑자기 커지면 느린 iPad는 몇 초 동안 약 11 fps까지 떨어질 수 있어요.
