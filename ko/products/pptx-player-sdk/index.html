무엇인가요

PPTX Player SDK는 PowerPoint .pptx 파일을 HTML과 SVG로 렌더링하고, 클릭할 때마다 다음 단계로 넘어가며 재생하는 클라이언트 사이드 JavaScript 엔진이에요. 입장·퇴장·강조 효과, 모프 전환, 포함된 미디어까지 다뤄요. 최신 브라우저나 WebView에서 오프라인으로 돌아가고, 서버 변환도 Office 설치도 필요 없어요. 전체 소스가 포함돼요.

자주 묻는 질문

PowerPoint 파일을 브라우저에서 애니메이션까지 재생할 수 있나요?

네. 엔진이 슬라이드마다 HTML/SVG로 렌더링하고, 클릭 순서대로 입장·퇴장·강조 효과, 모프 전환, 미디어를 넘겨요.

서버나 Microsoft Office가 필요한가요?

아니요. 모든 처리가 클라이언트에서 돌아가요. 플레이어 폴더를 아무 정적 웹 서버에 올리고 브라우저에서 열면 돼요.

오프라인이나 네이티브 앱 안에서도 되나요?

네. 오프라인으로 돌아가고, iOS·iPadOS·macOS에서는 같은 폴더를 WKWebView에 올릴 수 있어요. Android와 Electron WebView도 같은 방식으로 동작해요.

슬라이드 XML이 깨져 있으면 어떻게 되나요?

엔진이 잘못 들어간 & 문자를 고쳐서 슬라이드를 정상으로 재생해요. 그래도 XML이 깨져 있으면 할 수 있는 만큼 렌더링하고 오류를 알려요. 슬라이드를 조용히 빠뜨리지는 않아요.

구독인가요?

아니요. 1회 구매이고 전체 소스가 포함돼요.

JavaScript용 무료 PPTX 뷰어도 있나요?

네. 예를 들어 @web-ppt/viewer-core와 pptx-viewer가 있어요. 서버 없이 전체 소스가 있는 클라이언트 사이드 엔진 하나를 쓰고 싶고, 포크를 관리하느니 한 번 결제하고 싶다면 이 SDK를 고르면 돼요.
