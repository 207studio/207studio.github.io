무엇인가요

QR Answer-Sheet Cropper는 스캔한 시험지를 다루는 Python + OpenCV 도구예요. 답안지마다 작은 QR을 인쇄하고, 스캐너에서 나온 뒤섞인 묶음을 넣어요. 페이지마다 QR로 찾아내고 앞면과 뒷면을 짝지어요. 회전과 기울기를 바로잡고 답안 칸마다 약 200 dpi의 반듯한 이미지로 잘라요. 오프라인으로 돌아가요.

빠르게 시작하기

pip install -r requirements.txt
python demo.py
open out/

자주 묻는 질문

QR 코드로 스캔한 시험지의 답안 영역을 어떻게 자르나요?

답안지마다 QR 값을 인쇄하고, 묶음을 스캔한 뒤 크로퍼를 실행해요. 페이지 모서리의 QR을 읽고 답안 표를 밀리미터 격자에 맞춰 보정한 다음 칸마다 잘라요. Python에서는 데모를 실행하면 페이지마다 QR로 찾아내고, 템플릿에 맞춰 기울기를 바로잡고, 답안 칸마다 이미지 하나로 잘라요.

뒤섞인 스캔 묶음을 학생별로 정렬할 수 있나요?

네. QR 코드로 학생마다 앞면과 뒷면을 짝지어요. 다른 시험의 페이지는 '다른 시험 페이지(stray)'로 표시해요.

회전이나 기울기가 있어도 되나요?

네. 기울기와 90/180/270도 회전을 처리해요.

스캔 해상도는 얼마나 필요하나요?

150 dpi 이상이면 돼요. 데모는 200 dpi를 써요.

실행하려면 무엇이 필요한가요?

Windows, macOS, Linux에서 Python 3.10 이상, opencv-python-headless, numpy가 필요해요. 1회 구매이고 전체 소스가 포함돼요.
