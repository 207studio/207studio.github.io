무엇인가요

Scan-to-Grade는 스캔한 답안지 묶음을 Excel 성적표로 바꾸는 Python 패키지예요. 각 페이지의 QR을 읽고 앞면과 뒷면을 짝지어요. 기울기를 바로잡고 답안 칸마다 잘라낸 뒤, 버블과 복수 답안, O/X 문항, 순서 버블을 채점해요. 점수와 문항 분석, 다시 확인할 목록을 만들고, 오프라인으로 돌아가요.

빠르게 시작하기

pip install -r requirements.txt
python demo.py
open out/

자주 묻는 질문

스캔한 종이 시험지를 자동으로 Excel 성적표로 바꿀 수 있나요?

네. 스캐너에서 나온 묶음을 폴더에 넣고 실행하면 돼요. 점수와 문항 분석, 다시 확인할 목록이 든 gradebook.xlsx와 results.json, recheck.csv를 받아요.

학생 데이터가 컴퓨터 밖으로 나가나요?

아니요. Windows, macOS, Linux에서 오프라인으로 돌아가요. 어디에도 업로드하지 않아요.

페이지 순서나 회전이 뒤섞여도 되나요?

네. 페이지마다 QR이 있어서 뒤섞인 묶음, 뒷면, 90/180/270도 회전을 자동으로 정리해요.

손글씨나 서술형도 채점하나요?

아니요. 단답형, 서술형, 손글씨는 선생님이 맡아요. 잘라낸 답안 칸 이미지를 보고 확인할 수 있어요.

실행하려면 무엇이 필요한가요?

Python 3.10 이상, opencv-python-headless, numpy, openpyxl이 필요해요. 1회 구매이고 전체 소스가 포함돼요.
