자주 묻는 질문

시끄러운 방에서 음성 명령이 잘못 실행되는 걸 어떻게 줄이나요?

명령을 상황으로 걸러요. 엔진이 지금 어떤 단계인지 추적하고, 단계마다 명령을 허용하거나 웨이크 워드를 요구하거나 막아요.

상황은 어떻게 감지하나요?

단계와 설정한 전이, 음향 프로필(말하는 사람 수, 크기, 겹침, 주 화자 비율, 미디어 재생)에 확률 필터를 적용하고, 선택형 음성·앱 단서를 더해요. 1초에 한 번 갱신해요.

내 상황을 직접 모델링할 수 있나요?

네. TOML 파일에 단계, 길이, 전이, 음향 프로필, 명령 규칙을 정의하고 scene-engine validate로 검사한 뒤 시뮬레이션할 수 있어요. 교실, 회의, 매장 프리셋이 기본으로 들어 있어요.

내 앱에서는 어떻게 쓰나요?

Rust path 의존성으로 추가하고, 1초에 한 번 관측값을 SceneFilter에 넣고, 명령마다 gate::decide를 호출해요. CLI는 JSONL 관측값을 넣고 단계 스냅샷을 받을 수도 있어요.

클라우드나 Python이 필요한가요?

아니요. Rust 1.85 이상에서 로컬로 돌아가고, 계정도 API 키도 Python도 필요 없어요. 1회 구매이고 전체 소스가 포함돼요.

주변 대화가 음성 명령을 실행하지 않게 하려면 어떻게 하나요?

명령을 상황으로 걸러요. 엔진이 수업, 회의, 매장 같은 장면의 단계를 음향 특징과 단서로 1초마다 추정하고, 명령을 실행하거나 웨이크 워드를 요구하거나 막아요. Rust 라이브러리와 CLI로 오프라인에서 돌아가요.
