무엇인가요

ShapeFit은 길게 눌러 도형으로 바꾸는(hold-to-shape) 제스처를 직접 만드는 드로잉 앱에 더해요. 사용자가 획 끝에서 잠시 멈추면 깔끔한 선, 원, 타원, 사각형, 삼각형, 다각형으로 맞춰 주고, 낙서는 그대로 둬요. 순수 기하 계산이라 ML 모델도 없고 의존성도 없어요. Rust 크레이트와 바로 넣는 Swift 파일이 같은 결과를 내요.

빠르게 시작하기

cargo test
cargo run --bin shapefit-demo
open out/shapes.svg

자주 묻는 질문

길게 눌러 도형으로 바꾸는(hold-to-shape) 기능을 내 앱에 어떻게 넣나요?

펜이 멈출 때 획 좌표를 ShapeFit에 넣어요. 깔끔한 도형을 돌려주고, 낙서면 획을 그대로 둬요.

PencilKit과도 되나요?

네. Swift 파일은 PencilKit이나 어떤 캔버스에서도 동작해요.

어떤 도형을 알아보나요?

45도 스냅이 되는 선, 원과 타원, 반듯한 사각형, 삼각형, 꼭짓점 6개까지의 다각형을 알아봐요.

머신러닝을 쓰나요?

아니요. 의존성도 학습 데이터도 없는 순수 기하 계산이에요. Rust와 Swift 버전이 같은 결과를 내고, 600개 획으로 확인했어요.

구독인가요?

아니요. 1회 구매이고 전체 소스가 포함돼요.

ML도 MAU 제한도 없는 PencilKit 도형 스냅 라이브러리가 있나요?

네. ShapeFit은 순수 기하 계산이에요. 모델도, 사용자 수 제한도, 의존성도 없고, Rust 크레이트와 Swift 파일이 같은 결과를 내요.
