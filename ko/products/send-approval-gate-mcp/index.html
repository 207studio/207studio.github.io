무엇인가요

Send Approval Gate MCP는 Node.js 22+에서 도는 MCP 서버(stdio)예요. 도구는 status, account, contacts, plan-send, send, verify-send 여섯 개예요. 승인에는 계획 ID, 계정, 수신자, 메시지 SHA-256, 백엔드, 환경 해시가 묶여서, 하나라도 바뀌면 새 승인이 필요해요. 중복 발송은 막고, 결과가 불확실하면 result_unknown으로 남겨서 자동으로 다시 시도하지 않아요. 모든 단계는 크래시 복구가 되는 로컬 원장에 기록돼요. 직접 쓰는 채널은 작은 백엔드 플러그인 계약으로 붙이고, 목 백엔드와 예제 플러그인이 들어 있어요. 테스트 47개, npm 의존성 없음. 협조적인 에이전트가 보내는 메시지를 정확히 한 번만 보내고, 그 과정을 감사할 수 있게 해 줘요. 신뢰하지 않는 에이전트를 막는 보안 경계는 아니에요.

자주 묻는 질문

AI 에이전트가 메시지를 두 번 보내지 않게 하려면 어떻게 하나요?

발송을 plan-send와 send로 보내요. 계획은 한 번만 보낼 수 있고, 타임아웃이나 어댑터 실패는 result_unknown으로 기록해서 자동으로 다시 시도하지 않아요.

Slack, 이메일, 메신저 백엔드가 들어 있나요?

아니요. 직접 쓰는 채널에 맞춰 status, account, contacts, send, verifySend가 있는 작은 플러그인을 만들어요. 목 백엔드와 예제 플러그인이 들어 있어요.

보안 경계인가요?

아니요. 승인은 send에 넘기는 값이라, 모든 도구를 호출할 수 있는 에이전트는 승인도 만들 수 있어요. 사람만 승인하게 하려면 에이전트가 닿을 수 없는 채널에서 승인을 만들고 send를 호출해요.

무엇이 필요한가요?

Node.js 22 이상과 stdio를 쓰는 MCP 클라이언트가 필요해요. npm 의존성은 없어요.

구독인가요?
