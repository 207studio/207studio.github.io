Pairy

내 컴퓨터를 태블릿에서.

Pairy는 Mac의 화면과 키보드·트랙패드 조작을 iPad나 iPhone으로 이어 줘요. 화면을 직접 만지고, 입력하고, iPhone을 리모컨으로 써요.

App Store ↗Mac용 Pairy ↓

iPad, iPhone, Vision Pro와 Apple 실리콘 Mac을 함께 쓰는 분께. Windows 데스크톱 미리보기도 제공해요.

움직이는 모습

이렇게 써요

앱 두 개, 계정 하나. iPad·iPhone 앱이 Mac 화면을 보여 주고, Mac 동반 앱이 화면을 보내고 입력을 받아요.

  1. iPad나 iPhone에 Pairy 설치

    App Store에서 받아요.

  2. Mac에 Mac용 Pairy 설치

    아래에서 내려받고, macOS가 물으면 화면 녹화와 손쉬운 사용 권한을 허용해요.

  3. 같은 Tailscale 계정으로 로그인

    두 기기 모두에서요. Pairy가 내 컴퓨터를 찾고, 여러 대면 이름으로 골라요.

이렇게 보여요

  • FHD 화면 전송
  • 터치 트랙패드와 키보드 입력
  • 암호화된 내 기기 간 연결
  • 유화 밤하늘과 간결한 대시보드

Mac용 Pairy

iPad·iPhone 앱이 연결하는 Mac 동반 앱이에요. 저희에게서 바로 내려받아요.

Mac용 Pairy 다운로드

  1. zip 파일을 더블클릭해 압축을 풀고, PairyMac.app을 응용 프로그램 폴더로 옮겨요.
  2. 앱을 열고, macOS가 물으면 화면 녹화와 손쉬운 사용 권한을 허용해요.
  3. Pairy를 쓰는 동안 Mac은 켜 두고 네트워크에 연결해 두세요.

Apple 실리콘(M1 이상) Mac과 macOS 15 이상이 필요해요.

Windows 데스크톱 미리보기

Windows 화면을 공유하는 호스트와 데스크톱 접속 앱을 써 볼 수 있어요. 위의 App Store 앱·Mac 동반 앱과 별도로 제공하는 초기 시험판이에요.

Windows 미리보기 다운로드출시 안내·파일 검증값

  1. ZIP을 모두 풀고 START-HERE.txt를 읽어 주세요. 폴더의 파일을 함께 보관하세요.
  2. 두 컴퓨터에 Tailscale을 설치하세요. Pairy에서 Sign in을 누르고 공식 브라우저 화면에서 로그인 방법을 선택하세요. 두 컴퓨터에서 같은 Tailscale 사용자 계정을 사용하세요.
  3. 공유할 Windows에서 Share-screen.cmd를 열어요. 접속할 컴퓨터에서는 Connect.cmd를 열고 호스트의 Tailscale IP를 입력하세요.
  4. 호스트 창을 닫으면 공유가 끝나요. 접속 앱 창을 닫으면 연결을 종료해요.

미리보기 0.1.0 · Windows 10/11 64비트 · 설치 없이 쓰는 ZIP · 코드 서명 없음. 기본 모니터를 최대 1080p/30fps로 전송해요. 소리·클립보드 동기화·한글 조합 입력은 아직 지원하지 않아요.

Google·Apple·Microsoft·GitHub·Okta·OneLogin과 설정된 회사 계정으로 로그인할 수 있어요. 허용된 패스키도 Tailscale에서 선택해요. 기존 로그인 계정은 유지해요.

Windows 한 대 안에서 화면 전송과 Tailscale 계정 확인 시험을 통과했어요. 서로 다른 기기 간 연결과 Linux·Mac·iPad 호환성은 아직 검증하지 않았어요. 이번 미리보기에는 Linux·Mac 데스크톱 다운로드가 없어요.

알아 두세요

Tailscale 계정이 필요하고, 해당 서비스의 약관과 요금제가 별도로 적용돼요. 실제 화질과 반응 속도는 기기와 네트워크에 따라 달라져요. 문의: support@207studio.dev

자세한 설정

Pairy란

Pairy는 Mac 데스크톱을 iPad 화면 전체에 보여 줍니다. 화면을 눌러 포인터를 움직이고, 두 손가락으로 스크롤하세요. 떠 있는 메뉴를 열면 키보드, 받아쓰기, 클립보드, 화면 설정을 쓸 수 있습니다.

iPhone 앱에는 리모컨 모드가 있습니다. iPad가 Mac 화면을 보여 주는 동안, 같은 로컬 네트워크에 있는 iPhone이 iPad와 짝을 맺고 무선 키보드와 트랙패드 역할을 합니다. Mac 화면은 iPad에 그대로 남고, iPhone은 입력만 보냅니다. 하드웨어 키보드를 연결하면 iPhone에는 소프트웨어 키보드 없이 트랙패드만 표시됩니다. iPhone에는 Tailscale을 통해 Mac에 직접 연결해 화면을 보는 뷰어 모드도 있습니다.

iPad·iPhone 앱은 무료이며 강제 광고가 없습니다. 원하면 선택형 팁을 보내거나 직접 광고를 보는 방법으로 응원할 수 있고, 어느 쪽도 기능을 열지 않습니다. Mac 보조 앱은 무료이며 광고가 없습니다.

연결 방식

Pairy에는 Tailscale이 내장되어 있습니다. Mac과 iPad에서 같은 Tailscale 계정으로 로그인하세요. Pairy가 Mac을 찾고, 기기 사이의 연결은 Tailscale이 암호화합니다. IP 주소를 입력하거나 공유기에서 포트를 열 필요가 없습니다.

iPhone 리모컨 모드는 로컬 네트워크를 사용합니다. iPhone이 Bonjour로 Mac에 연결된 iPad를 찾고, iPad에서 연결을 확인하면 짝이 맺어집니다. iPhone은 키보드와 트랙패드 입력을 iPad로 보내고, iPad는 기존 Tailscale 연결을 통해 Mac으로 전달합니다. 리모컨 모드에서 영상은 iPad에만 표시됩니다.

iPhone에서 리모컨 모드를 처음 쓰면 iOS가 로컬 네트워크 접근을 요청합니다. 허용하지 않으면 iPhone이 iPad를 찾을 수 없습니다.

설정 순서

  1. Mac 보조 앱을 내려받아 Pairy를 응용 프로그램 폴더로 옮기고 실행하세요.
  2. Mac 앱에서 Tailscale에 로그인하세요. macOS가 요청하면 화면 녹화와 손쉬운 사용을 허용하세요.
  3. iPad나 iPhone에 Pairy를 설치하고 같은 Tailscale 계정으로 로그인하세요.
  4. Mac을 고르세요. 온라인 상태인 Mac이 하나면 자동으로 연결되고, 여러 대면 이름을 보고 고릅니다.
  5. iPhone 리모컨을 쓸 때는 iPad가 Mac 화면을 보여 주는 동안 iPhone에서 Pairy를 열고, 목록에서 iPad를 누른 뒤 iPad에서 연결을 확인하세요.

고급: 웹 로그인 대신 ‘인증 키로 로그인’을 눌러 Mac의 Tailscale 계정에서 만든 태그 없는 키를 붙여 넣을 수 있습니다. 키는 기기에 저장되지 않습니다. 다른 계정의 키를 쓰면 그 계정의 tailnet에 참여합니다. Mac이 없다면 첫 화면에서 ‘데모 사용’을 눌러 계정이나 네트워크 없이 가상 Mac을 써 볼 수 있습니다.
