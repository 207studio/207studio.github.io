What it is

Async Securities API Client is an asyncio Python package (Python 3.10+, httpx) for the Toss Securities Open API. It issues and reuses OAuth client-credentials tokens with one reissue on expiry, follows the server's x-ratelimit headers per group, builds Decimal-safe order bodies, and covers market data (prices, candles, order book, trades, rankings, market calendar), account (holdings, buying power, orders) and orders (create, cancel, OCO). Order writes are never re-sent after a 5xx or transport error. The order methods place real orders immediately: there is no paper mode, arming step or order-size limit. Not affiliated with Toss Securities.

FAQ

Does it trade for me?

No. It has no strategy and no automatic decisions; the order methods send a real order the moment you call them.

Can I try it without money at risk?

Not in this package: there is no paper mode, arming step or order-size limit. Add those in your own code before the first live call.

Do I need my own key?

Yes. Use your own Toss Securities app key, and register your calling IP in Toss Securities WTS; unregistered IPs get 403.

Can my company use it?

No. The Toss Securities terms exclude corporate customers, which is why there is only a Personal tier.

Is this an official Toss Securities product?

No. It is an independent client for the public Open API, not affiliated with or endorsed by Toss Securities.
