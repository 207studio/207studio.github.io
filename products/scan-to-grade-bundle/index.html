What it is

Scan-to-Grade is a Python package that turns a batch of scanned answer sheets into an Excel gradebook. It reads the QR on each page, pairs fronts and backs, deskews and crops every answer cell, grades bubbles, multi-answer marks, O/X parts and ordering bubbles, and writes scores, item analysis and a re-check list. It runs offline.

FAQ

Can I turn scanned paper tests into an Excel gradebook automatically?

Yes. Drop the scanner batch in a folder and run it. You get gradebook.xlsx with scores, item analysis and a re-check list, plus results.json and recheck.csv.

Does student data leave my computer?

No. It runs offline on Windows, macOS or Linux. Nothing is uploaded.

Can the pages be scanned in any order or rotation?

Yes. Each page carries a QR, so mixed batches, back sides and 90/180/270-degree turns are sorted out automatically.

Does it grade handwriting or essays?

No. Short answers, essays and handwriting stay with the teacher, who sees the cropped cell images.

What do I need to run it?

Python 3.10+, opencv-python-headless, numpy and openpyxl. One-time purchase, full source included.
