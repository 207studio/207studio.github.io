What it is

Answer Sheet OMR & Auto-Grader is a Python OMR engine for scanned answer sheets. Beyond A–E bubbles, it reads multi-answer marks, circled words, O/X boxes and ordering bubbles. It fills in only grades it is confident about, never overwrites a mark a teacher already made, and sends the rest to a re-check list. Runnable demo exports to Excel.

FAQ

Which mark types can it read?

Single and multi-answer bubbles, circled words, O/X boxes and ordering bubbles.

Will it overwrite grades a teacher already entered?

No. It fills only confident grades, keeps existing teacher marks and lists any disagreement for re-checking.

Is there an open-source alternative?

Yes, for example OMRChecker (MIT) for bubble sheets. This engine adds O/X, circled-word and ordering items and the confident-only grading rule.

Does it work with my scanner?

It works on scanned images from any scanner. Pair it with the QR Cropper, or get both in the Scan-to-Grade Bundle.

Is it a subscription?

No. One-time purchase, full source included.
