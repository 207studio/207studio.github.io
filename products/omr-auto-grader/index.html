What it is

OMR Auto-Grader is a Python OMR engine for scanned answer sheets. Beyond A–E bubbles, it reads multi-answer marks, circled words, O/X boxes and ordering bubbles. It fills in only grades it is confident about, never overwrites a mark a teacher already made, and sends the rest to a re-check list. Runnable demo exports to Excel.

FAQ

Which mark types can it read?

Single and multi-answer bubbles, circled words, O/X boxes and ordering bubbles.

Will it overwrite grades a teacher already entered?

No. It fills only confident grades, keeps existing teacher marks and lists any disagreement for re-checking.

Is there an open-source alternative?

Yes, for example OMRChecker (MIT) for bubble sheets. This engine adds O/X, circled-word and ordering items and the confident-only grading rule.

Does it work with my scanner?

It works on scanned images from any scanner. Pair it with the QR Cropper, or get both with Scan-to-Grade.

Is it a subscription?

Is there a commercial OMR library without AGPL terms?

Yes. This engine ships under the 207studio license with full source; MarkShark is AGPL and OpenMCR is GPL-3.
