What it is

FAQ

Can I play a PowerPoint file in the browser with its animations?

Yes. The engine renders each slide to HTML/SVG and steps through the click sequence: entrance, exit and emphasis effects, morph transitions and media.

Does it need a server or Microsoft Office?

No. Everything runs client-side. Serve the player folder from any static web server and open it in a browser.

Does it work offline or inside a native app?

Yes. It runs offline, and on iOS, iPadOS and macOS you can load the same folder in a WKWebView. Android and Electron WebViews work the same way.

What happens with a slide whose XML is broken?

The engine repairs stray & characters and plays the slide normally. If the XML is still broken, it renders what it can and reports an error instead of dropping the slide silently.
