FAQ

Can I make an OMR answer sheet that matches my exam automatically?

Yes. The bubble sheet is generated from the same exam data as the paper and the answer key, so they always match.

Does it need an account or install?

No. The editor is a single HTML file that opens with a double-click, with live preview and autosave.

Which question types are supported?

Passages, images, tables, graphs, multiple choice with any number of options, short answer, essay, blanks and ordering.

Can an AI assistant build exams with it?

Yes. The included MCP server lets an AI assistant draft, validate and render exams with the same renderer.

How do I print?

A4 through the browser; save as PDF from the print dialog. One-time purchase, full source included.
