What it is

PadswayCore SDK is a pure-Swift package for macOS 13+ and iPadOS 17+ that streams a Mac screen to an iPad. It captures with ScreenCaptureKit, encodes and decodes with VideoToolbox H.264/HEVC at 60 or 120 fps (Full HD), paces frames by the iPad's acknowledgements to keep lag low, and sends pointer, keys, text, Apple Pencil and clipboard back over TLS 1.2 with a per-pairing key. FAQ

How do I stream a Mac screen to an iPad in Swift?

Add PadswayCore to both apps. On the Mac create a Pairing and start a HostSession; on the iPad decode the pairing and connect a ClientSession, then draw each CVPixelBuffer it hands you. INTEGRATION.md has the full wiring, and that code is compiled by the test suite.

Can I try it without a Mac, network or permissions?

Yes. `swift run padsway self-test` encodes 120 frames, sends them over TLS on loopback and decodes them in about 2 seconds, and ClientSession.demo() streams a simulated Mac in-process for onboarding and App Review.

Can the Mac side ship on the Mac App Store?

No. The host injects input through the Accessibility API, so it can't run sandboxed. Ship it as a signed, notarized app. The iPad side has no such limit.

Does it work over the internet?

It works on the local network out of the box. An optional bridge built on the open-source tsnet library is included as source for use without port forwarding.

What frame rate and resolution?

Full HD (1920×1080). 120 fps is requested on ProMotion iPads and 60 fps elsewhere; it is not a throughput guarantee. After a sudden network-delay jump a slow iPad can drop to about 11 fps for a few seconds.
